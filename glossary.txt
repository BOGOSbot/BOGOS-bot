# BOGOS bot glossary.
#
# One name per line. Blank lines and lines starting with # are ignored.
#
# The bot transcribes a French-speaking Warhammer 40,000 tournament team: army
# lists, pairings and matchups, then travel, accommodation and payment. This is
# the vocabulary of that in general. What is nobody else's business - your
# armies, your players, the venue, the gite - goes in glossary.local.txt, which
# is gitignored and read after this one.
#
# It is attached to every transcription request, so its size is paid on every
# chunk. Add a line whenever a session comes back with a name spelled wrong.
# The whole Warhammer 40,000 corpus is about 42,000 tokens, 95% of a one-minute
# chunk, so this stays a core list and grows from what the meetings get wrong.
#
# Read fresh before each request, so an edit applies to the next chunk without a
# restart. Point STT_GLOSSARY_FILE somewhere else, or set it empty to turn the
# glossary off.
